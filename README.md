# Sparc HR

A modular HR system prototype for Sparc Systems built with Laravel framework. For the prototyping phase it will feature only one module -- Vacancies.

### Vacancies Module

This module will allow the HR team to publish and manage employment vacancies including applications from candidates.

It will also be responsible for automatically scoring candidates based on specified criteria using AI.

> This is intended to showcase fullstack development skills as well as the ability to design, develop and deploy a fullstack application.
